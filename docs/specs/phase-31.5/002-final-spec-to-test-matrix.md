primary evidence. Entries labelled **static-only** are intentionally weaker:
they establish a reviewed source, document, or package declaration but do not

## Publication and documentation

- `scripts/release/phase31_5-published-journey.test.mjs` rebuilds each required
  workspace before `npm pack`, extracts only the resulting tarballs into an
  isolated temporary fixture, derives the packed runtime dependency graph,
  resolves the packed web-server export, checks packed `--help`, validates the
  shipped schema/README/runtime assets, and rejects test-only model
  catalog/probe fixture paths.
- `npm run verify:pack` is the repository-wide package allowlist gate.
- Root/package READMEs, schema/target/CLI/privacy documentation, and
  [`docs/research/012-model-policy-mapping-v3-evidence.md`](../../research/012-model-policy-mapping-v3-evidence.md)
  are **static-only** publication evidence. The packed journey validates only
  the Phase 31.5 documents' relative local links; it does not claim a
  repository-wide documentation-link validator.

## Remaining evidence limits

- Provider entitlement, quota, and runtime fallback are deliberately not
  claimed: target clients remain authoritative and fake probes only validate
  Agent Profile's local invocation/result contract.
- Official-client documentation and client-version observations are
  release-pinned evidence and can drift; the catalog evidence records its
  verification date.
- No test reads credentials, repository source for a probe, account identity,
  or private endpoint. Those absences are enforced at the tested boundaries;
  the broader no-telemetry/no-hosted-execution design remains **static-only**.
