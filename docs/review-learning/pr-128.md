### `pr-128#thread-2`

Unsafe behavior: This hardcodes consent as granted without showing the exact client processes/candidates, the bounded call count, or possible provider quota use before execution. ### `pr-128#thread-3`
- Fingerprint: `["network-process-boundary","network-process-boundary",{"path":"apps/cli/src/index.ts","symbol":null,"line":null},"unsafe-ordering"]`
- Precondition: For a profile with only Codex or only Claude enabled. Unsafe behavior: ResolveModelPolicyLockfile still contains resolution rows for both clients, and this loop selects both without consulting profile.clients. ### `pr-128#thread-4`
- Fingerprint: `["network-process-boundary","network-process-boundary",{"path":"apps/cli/src/index.ts","symbol":null,"line":null},"unsafe-ordering"]`
